## 📋 現在の実装状況（2025年1月）

### ✅ 写仏画ギャラリー実装済み機能
1. **ヒーローセクション**
   - 横スクロール（10秒ごとの自動切り替え）
   - 手動スクロール（◀︎▶︎ボタン）
   - スマホスワイプ対応
   - 無限ループ（4枚目→1枚目が自然に）
   - 下部グラデーションのみ「福本正　写仏画ギャラリー」表示

2. **ナビゲーション**
   - 「仏像の世界」ロゴ
   - ホーム、ギャラリー、篆刻作品集（新規追加）、作者について

3. **検索機能**
   - 仏像名での検索（弁財天、観音、地蔵など）

4. **タブ切り替え**
   - すべて、如来、菩薩、明王、天部

5. **ギャラリー**
   - 作品カード（シンプル表示）
   - NEW!バッジ（落ち着いた色調）
   - モーダルで詳細表示

6. **モーダル**
   - 大きな画像表示（60vh）
   - 詳細情報は折りたたみ式
   - 「詳細を表示/閉じる」ボタン

7. **フッター**
   - コピーライト表示
   - 篆刻作品集へのリンク追加（2025年1月）
   - 落ち着いたグラデーション背景

8. **レスポンシブ対応**
   - スマホ時のテキストサイズ調整
   - ◀︎▶︎ボタンのサイズ調整（35px）

## 📝 次回の開発時の注意点
1. 画像ファイルの追加時は各ディレクトリの `/images/` に配置
2. CSSとJSは現在インラインなので、必要に応じて外部ファイル化
3. 作品データは各ページ内の配列に追加
   - 写仏画: `buddhaData` 配列
   - 篆刻: `sealData` 配列
4. コミットメッセージは日本語でOK
